# Sales Analytics Dashboard

A production-quality MVP Sales Analytics Dashboard for small-business users.

## Features

- Upload CSV, XLSX, or XLS files
- Validate and clean uploaded data
- Calculate sales KPIs
- Analyze products, categories, regions, and trends
- Generate dynamic business insights
- View data-quality metrics
- Filter by date, category, region, and product
- Use built-in sample data

## Tech Stack

- Python 3.11+
- Streamlit
- pandas
- NumPy
- Matplotlib
- Seaborn
- openpyxl
- pytest
- python-dotenv
